IriX 是一个开源的 Android 客户端，用于管理 MCSM 风格的服务器节点（兼容 IriX-Node 守护进程与 MCSManager 节点）。

功能：

* 概览：系统信息、CPU / 内存 / 磁盘使用率、网络吞吐与实例统计，15 秒自动刷新
* 实例管理：实例列表、启动 / 停止 / 重启 / 强杀、控制台命令下发、日志查看（支持自动刷新）、配置编辑（启动命令、工作目录、编码、自动启动 / 自动重启）、新建与删除实例
* 文件管理：实例工作目录浏览（面包屑导航）、新建目录 / 文件、重命名、删除、文本在线编辑、直连下载（系统下载管理器）与直连上传（multipart）
* 容器环境：运行时信息（Docker / Bastille）、容器列表与生命周期控制（启动 / 停止 / 重启 / 强杀 / 删除）、新建容器（镜像、命令、端口映射、数据卷、环境变量、重启策略、资源限制）
* 节点管理：多节点增删改、一键切换选中节点、API Key / 配对码配置，配置本地持久化（DataStore）

网络说明：

* 应用通过 HTTP 或 HTTPS 连接你自己的局域网节点。明文 HTTP 仅允许回环 / 私有 / 链路本地地址；公网地址强制使用 HTTPS（由内置 NetworkPolicy 在输入与请求两个环节拦截）
* 应用仅使用 INTERNET 与 ACCESS_NETWORK_STATE 权限。无广告、无跟踪、无统计。
